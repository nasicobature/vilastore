How It Works

1. Register as agent Your verified agent account can publish property listings.

Once your account is verified, listings you add can be approved and shown in the marketplace.

2. Add property details Capture photos, location, pricing, and availability.

Each listing supports pictures, rent or sale mode, property type, and a clear status.

3. Marketplace visibility Approved active listings appear beside shop listings.

When a listing is active, approved, and set to show in marketplace, it becomes visible to buyers automatically.
