# VilaAgent Default Rules

1. Do not push directly to `main`.
2. Do not delete existing features without explicit approval.
3. Do not rewrite unrelated code.
4. Keep changes focused on the user task.
5. Prefer small patches.
6. Run checks/tests when possible.
7. Never print or commit secrets.
8. Use Git branches such as `codex/bug-fixes` or `codex/shop-management`.
9. Save generated patches before applying them.
10. Ask for human review before merge.
